1 Skill Set Score Active
Definition

Measures how well candidate skills match JD required skills.

Comparison Logic

Required skills from JD vs. Skills listed in resume experience sections.

Positive Indicators
  • Exact skill match
  • Multiple required skills present
  • Hands-on usage mentioned
Negative Indicators
  • Skills only listed without experience
  • Partial skill overlap
Evidence Rule

Score only when skills explicitly mentioned.
2 Qualification Score Active
Definition

Measures alignment between required education and candidate education.

Comparison Logic

JD required degree vs. Resume education section.

Positive Indicators
  • Exact degree match
  • Equivalent degree
  • Higher qualification in same domain
Negative Indicators
  • Different field
  • Lower qualification
Evidence Rule

Score only if education explicitly stated.

3 Certification Score Active
Definition

Measures relevance of certifications compared to JD requirements.

Comparison Logic

JD required/preferred certifications vs. Resume certifications.

Positive Indicators
  • Required certification present
  • Multiple relevant certifications
  • Recent certification
Negative Indicators
  • Irrelevant certifications
  • Expired (if imp.)
Evidence Rule

Score only if certification clearly mentioned.
4 Relevant Experience Score Active
Definition

Measures how closely candidate experience aligns with JD role.

Comparison Logic

JD responsibilities vs. Resume role descriptions.

Positive Indicators
  • Same job role
  • Similar responsibilities
  • Relevant domain
Negative Indicators
  • Different role scope
  • Only indirect experience
Evidence Rule

Score only if role description exists.
5 Overall Experience Score Active
Definition

Measures total professional experience against JD expectations.

Comparison Logic

JD required years vs. Resume total years.

Positive Indicators
  • Meets required years
  • Career progression
Negative Indicators
  • Below required experience
  • Major unexplained gaps
Evidence Rule

Score only if duration identifiable.
6 Key Responsibilities Score Active
Definition

Measures similarity between JD responsibilities and candidate duties.

Comparison Logic

JD responsibility section vs. Resume responsibility bullets.

Positive Indicators
  • Similar tasks
  • Similar ownership level
  • Project involvement
Negative Indicators
  • Generic descriptions
  • Different responsibility level
Evidence Rule

Score only if responsibilities described.

7 Overall Suitability Score Active
Definition

Weighted overall match based on all dimensions.

Comparison Logic

System calculated aggregate score.

Evidence Rule

Exclude dimensions marked N/A from calculation.
